Description détaillée

Classe Recette pour représenter une recette de cuisine.

Cette classe permet de gérer les informations d'une recette, telles que l'identifiant, le nom, la description, l'image, la catégorie et les ingrédients quantifiés.

La catégorie est représentée par un objet Categorie et les ingrédients sont mémorisés dans un tableau d'objets IngredientQuantifie.
